# Private source data (do not upload)

Download the original SupeRR Selector Season 2 data pack from Unstop's **Brief/Case** button.
Place the ZIP here as `organizer_data_pack.zip` for local analysis.

The organiser's Unstop rules state that the proprietary data pack is for competition use only and must not be shared or published. This folder is git-ignored intentionally. Do not remove that protection and do not upload the ZIP or its raw CSVs to GitHub, a public drive, or a public website.

Run the analysis locally with:

```bash
python analysis/build_rankings.py
```
